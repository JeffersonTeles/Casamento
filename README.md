## 📌 Sobre o Projeto

Landing page completa para evento, desenvolvida do zero com HTML, CSS e JavaScript puro — sem frameworks.  
O objetivo era criar uma página leve, rápida e funcional, acessível em qualquer dispositivo.

---

## ✨ Funcionalidades

- ✅ **Countdown em tempo real** — contador regressivo com JavaScript até a data do evento
- ✅ **Formulário de confirmação** — integração direta com WhatsApp via API link
- ✅ **Galeria de fotos** — seção visual do evento
- ✅ **Design responsivo** — adaptado para desktop e mobile
- ✅ **Deploy em produção** — hospedado via GitHub Pages

---

## 🛠️ Stack

## ⚙️ Como Funciona

**Countdown:**
```javascript
// Lógica de countdown em tempo real
// Calcula diferença entre data atual e data do evento
// Atualiza dias, horas, minutos e segundos a cada 1 segundo
```

**Formulário → WhatsApp:**

Usuário preenche nome e confirma presença
→ JavaScript monta a mensagem
→ Redireciona para WhatsApp com texto pré-preenchido
→ Zero backend necessário
