# Sugestões de Melhorias para o Sistema de Convites

## Funcionalidades Atuais
- ✅ Painel de organização com gestão de convidados
- ✅ Separação de convidados por dono (Jefferson, Bia, Ambos)
- ✅ Sistema de RSVP via token
- ✅ Controle de tarefas e financeiro

## Sugestões de Melhorias

### 1. Página Pública de Convite
- **Página de boas-vindas** com foto do casal, data e local do casamento
- **Formulário de RSVP** acessível via link único por convidado (token)
- **Design responsivo** para mobile e desktop
- **Contagem regressiva** para o dia do casamento
- **Informações do evento**: horário, local, mapa, dress code

### 2. Sistema de Convites Digitais
- **Geração automática de links** para cada convidado com token único
- **Personalização do convite** com nome do convidado
- **Opção de enviar convite por WhatsApp** (link direto)
- **Template de e-mail** para envio em massa
- **QR Code** para cada convite (impressão física)

### 3. Funcionalidades de RSVP Avançadas
- **Seleção de acompanhantes** (+1, +2, etc)
- **Restrições alimentares** (alergias, vegetariano, etc)
- **Mensagem para o casal** (campo de texto livre)
- **Confirmação com foto** (upload opcional)
- **Lembrete automático** por e-mail/WhatsApp para quem não confirmou

### 4. Gestão de Acompanhantes
- **Campo de acompanhantes** na tabela guests
- **Limite de acompanhantes** por convidado (configurável)
- **Lista de espera** para quando atingir limite
- **Separar confirmação principal de acompanhantes**

### 5. Dashboard de RSVP
- **Gráfico de confirmações** em tempo real
- **Taxa de resposta** (confirmados / total)
- **Lista de não respondidos** com opção de reenviar convite
- **Estatísticas por dono** (Jefferson vs Bia)
- **Exportação para Excel/PDF** da lista final

### 6. Comunicação com Convidados
- **Sistema de notificações** por e-mail
- **Template de mensagem** para WhatsApp
- **Lembretes automáticos** (7 dias, 3 dias antes)
- **Agradecimento** após confirmação
- **Atualizações do evento** (mudança de local, horário, etc)

### 7. Funcionalidades Extras
- **Galeria de fotos** do casal
- **Lista de presentes** (link para lista de casamento)
- **Informações de hospedagem** (hotéis próximos)
- **Dicas de transporte** (como chegar)
- **Música** (playlist sugerida ou campo para pedir música)

### 8. Segurança e Privacidade
- **Proteção por senha** para página de convites
- **Opção de ocultar lista** de convidados confirmados
- **Log de acessos** (quem visualizou o convite)
- **Validação de e-mail** ao confirmar RSVP

### 9. Relatórios e Exportação
- **Relatório de convidados confirmados** por grupo
- **Lista final para buffet/catering**
- **Lista para decoração** (mesas, cadeiras)
- **Exportação em CSV/Excel**
- **Impressão de crachás/nomes**

### 10. Integrações
- **Integração com Google Maps** para local
- **Integração com Google Calendar** (adicionar ao calendário)
- **Integração com WhatsApp Business** para mensagens
- **Integração com serviço de e-mail** (SendGrid, Mailchimp)
